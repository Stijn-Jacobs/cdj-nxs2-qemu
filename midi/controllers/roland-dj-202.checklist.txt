# The DJ-202's controls, as a checklist for learn.py.
#
# These are NAMES ONLY -- no MIDI numbers appear anywhere in this file, and
# none should be added by hand. The numbers come from the device itself, via
# `learn.py learn`, which walks this list and records what each control
# actually sends. That is the whole point: nothing in this project trusts a
# published chart over a measurement.
#
# The list is best-effort from the front panel layout. It does not have to be
# right. Learn mode lets you skip anything that is not there (ENTER), and its
# free mode captures controls this file never mentions, so a wrong or missing
# line costs nothing.
#
# Format: one control per line, `group/name`. Lines starting with # are
# comments. Anything after `--` on a line is a hint printed during learn.
