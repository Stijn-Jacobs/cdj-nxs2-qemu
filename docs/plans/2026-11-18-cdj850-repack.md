# CDJ-850 MAIN repacker — plan

**Goal:** turn a (possibly modified) unpacked MAIN image back into a
`C850MAIN.UPD` that the CDJ-850's bootloader and updater accept. Prove it
first with a byte-identical repack of the stock v1.13 file, then by
booting a patched image in the emulator.

**Branch / worktree:** `cdj850-repack` off `cdj850-bringup`. `extract/`
is a symlink to the main checkout's untracked `extract/`; firmware bytes
are never committed.

**Tools:** pyghidra-mcp for every firmware question (bootloader verify,
updater flash-write path, length rules); Python stdlib only for the tool
(matches the `scripts/firmware/` rules); pytest for tests.

## What is already known (2026-11-18)

| item | value | source |
|---|---|---|
| packed field | UPD `0x60020`: BE32 stream length `0x19E6E6`, stream `0x60024–0x1FE70A` | `c850_unpack.py` |
| codec | Okumura LZSS, ring 4096, fill `0x20`, start pos 4078, `len=(b2&0xF)+3` (3..18), absolute ring offset | `lzss_decode.py` |
| trailer | `0xFB71` BE16 at `0x1FE70A` = 16-bit sum of bytes `0x60020–0x1FE70A` (length field + stream) | measured today; **needs firmware confirmation** |
| file length | `0x20E70C` = stream end + 2 + `0x10000` zero pad (hypothesis) | measured; **needs firmware confirmation** |
| label | `CDJ-850 MAIN` + `1.13` at `0x60000` (32 B) | `c850_decode.py` |
| boot region | `0x0–0x40000` code, `0x40000–0x60000` erased `0xFF` | layout notes |

## Unknowns to close (pyghidra-mcp)

1. **Bootloader verify** (`boot.bin`): which bytes the boot-time check sums,
   what it compares against, and what happens on mismatch.
2. **Updater** (in MAIN, near the `C850MAIN.UPD` string / `usbTask`):
   which checks it runs on the file (size, label, model string, version,
   checksum), which flash ranges it erases and programs (does it reflash
   `boot`?), and where `E-7024` comes from.
3. **Length rule:** does anything depend on the file length, or only on
   the BE32 field? This decides whether a bigger or smaller stream is safe
   and what the pad must be.
4. **Size ceiling:** the MAIN region ends at flash `0x200000`, so the
   packed data + 2 bytes must fit. The unpacked image must not overlap the
   bootloader's staging area (`0x0DDEFA20` per notes).

Each answer goes into `notes/cdj850-layout.md` with function addresses,
and the Ghidra project gets matching renames and comments.

## Build steps

1. **Encoder** `scripts/firmware/lzss_encode.py`: Okumura binary-tree
   encoder with the same parameters. The target is byte-identical output
   to the stock stream, matching `lzss.c` tie-breaking. If that can't be
   reached, fall back to output that decodes identically and say so;
   that is enough for the device.
2. **Repacker** `scripts/firmware/c850_repack.py
   <stock.UPD> <main_unpacked.bin> <out.UPD>`: keeps `boot` + label from
   the stock file, then compresses and writes length, stream, checksum
   and pad. It re-reads its own output through the existing unpacker and
   refuses to write on a mismatch, and it enforces the size ceiling.
3. **Check mode** `c850_repack.py --check <file.UPD>`: recompute and
   report length/checksum/label validity.
4. **Tests** `tests/test_cdj850_repack.py`: synthetic encoder round-trips
   (no firmware bytes) and checksum vectors. When the stock file is
   present, also test that the stock repack is byte-identical.
5. **Emulator proof:**
   a. a flash image built from the repacked stock UPD boots like stock;
   b. a minimal visible patch (a boot/display string) repacks, passes
      `--check`, boots, and shows the change;
   c. stretch: run the in-firmware USB updater with the patched UPD,
      but only if the updater entry is reachable in the emulator.
6. Docs: container rules in `notes/cdj850-layout.md`, plus a short
   how-to-repack note. No hardware flash in this plan.

## Done when

- the stock repack is byte-identical (or decodes identically, with the
  reason written down) and the tests pass;
- the bootloader and updater checks are named with addresses in the notes;
- a patched UPD boots in the emulator with the visible change.

## Out of scope

Flashing a real deck; panel/servo/DSP firmware (not in the update);
wiring the 850 into `mods/patch_update.py` (follow-up once real mods
exist).
